# Local Voice Studio v1.4.0

이 폴더의 내용을 GitHub 루트에 업로드하세요. Vercel은 vercel.json 설정으로 빌드합니다.

사용자는 manual.html의 Windows 설치·복구 프로그램 버튼으로 단일 EXE를 내려받습니다. ZIP 압축 해제나 CMD/PowerShell 파일 직접 실행은 요구하지 않습니다. 설치 창의 설치 시작/연결 복구 버튼과 변경 확인 창으로 진행합니다.

설치 위치는 현재 Windows 사용자의 LocalAppData/LocalVoiceStudio/1.4.0입니다. 기존에 등록된 설치 환경과 모델을 검사해 재사용합니다. 프로그램 파일은 같은 버전의 내용이 다르면 덮어쓰지 않고 중단합니다. 연결 설정 변경은 사용자 확인을 받고 기존 설정을 백업합니다. 복구는 모델/패키지를 다운로드하지 않습니다.

downloads에는 실제 Windows 설치 EXE가 포함됩니다. 2026-10-22-windows-source는 내부 엔진 소스이며 사용자가 직접 실행할 필요가 없습니다. 2026-10-22-installer.cs와 2026-10-22-build-installer.ps1은 설치 EXE 재빌드용 소스입니다. 이 빌드는 Windows .NET Framework C# 컴파일러를 사용하며 Vercel 빌드에서는 실행하지 않습니다.

엔진은 웹에서 시작하며 탭 연결이 끊기면 작업 완료 후 종료합니다. 기존 외부 Ollama는 보존합니다. 설치기의 로컬 검사와 실제 브라우저 앱 열기/사이트 승인은 별도 단계입니다.

설치 EXE는 코드 서명되지 않은 베타입니다. 리소스 무결성·컴파일·내부 엔진 검증과 실제 새 PC 설치/공개 웹 연결 검증은 구분해야 합니다. 개인 모델·설정·캐시·로그는 업로드하지 않습니다.
