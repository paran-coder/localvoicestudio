01 / SOURCE

화면 왼쪽 위에서 YouTube 링크나 영상·음성 파일을 선택하고 자막을 추출하세요. 이미 대본이 있다면 아래 직접 입력 칸에서 시작할 수 있습니다.

02 / VOICE

목소리 설정·화자 등록

원본 가져오기 옆에서 인물을 추가하고 각 인물의 참조 음성을 연결하세요. 한 목소리만 쓴다면 단일 샘플을 사용합니다. 인물별 샘플이 없으면 기본 목소리로 생성됩니다.

대본 편집·화자 배정

05 / GENERATE

음성 생성

번역 아래에서 생성 전 번역 여부와 원본 시작 시각 참고 설정을 확인하고 음성을 생성하세요. 분리한 구간 시간은 추정값이므로 검토가 필요합니다. 긴 발화는 후속 구간을 늦출 수 있습니다.

06 / RESULT

작업 상태·생성 결과

화면 맨 아래에서 진행 상황과 오류를 확인하세요. 전체 더빙과 이름이 표시된 인물별 음성을 들어보고, 자막·ZIP·검수 자료를 다운로드해 영상 동기화를 확인하세요.

로컬 엔진 설치·연결

더빙하려면 내 PC의 로컬 엔진을 연결하세요. 먼저 엔진이 응답하는지 확인합니다. 연결 코드는 엔진을 찾은 다음에만 필요합니다.

아래 버튼을 눌러 엔진을 확인하세요.

처음 사용하시나요?

엔진이 응답하지 않습니다. 미설치인지 실행 중지인지 웹에서 구분할 수 없으므로 아래 두 가지를 확인하세요.

로컬 엔진 다운로드
  1. 처음이라면 ZIP 전체를 압축 해제하고 2026-10-22-engine-start.vbs를 실행하세요. 최초 설치 안내에 동의하면 환경을 준비합니다.
  2. 이미 설치했다면 같은 파일을 실행해 엔진을 켜세요. 설치 후에는 트레이에서 동작합니다.
  3. 엔진이 실행되면 위 ‘엔진 연결 확인’을 다시 누르세요. 브라우저가 로컬 네트워크 권한을 요청하면 안내를 확인하세요.

매뉴얼을 별도 창으로 열어 편집 화면의 대본·화자 배정·선택한 파일을 유지합니다. 엔진을 재시작하거나 편집 페이지를 새로고침하면 재연결이 필요합니다.

처음 실행할 때

웹 편집 화면을 열고 로컬 엔진을 연결하세요. 최초 설치에는 안내 창이 표시되며, 설치 후 엔진은 트레이에서 실행됩니다. 연결 코드는 신뢰하는 웹 편집 화면에만 입력하세요.

웹 연결 버전의 사용 순서

  1. 웹 편집 화면 오른쪽 위 로컬 엔진 연결을 눌러 이 매뉴얼을 열고, 위 엔진 연결 확인을 누릅니다.
  2. 연결되지 않으면 설치 또는 엔진 실행 안내를 확인합니다. 연결 실패만으로 미설치와 실행 중지를 구분할 수는 없습니다.
  3. 처음 사용하는 PC라면 Windows 패키지를 내려받아 압축을 해제하고, 기존 환경의 검사 결과와 설치 계획을 확인하세요. 호환되는 Python·패키지·Ollama·모델·FFmpeg는 재사용하고, 부족한 항목만 동의 후 준비합니다.
  4. 로컬 엔진을 실행한 뒤 이 매뉴얼에서 다시 확인하고, 엔진을 찾으면 트레이의 연결 코드를 입력해 승인합니다. 브라우저가 로컬 네트워크 접근 권한을 요청하면 안내를 확인합니다.
  5. 연결 완료 후 편집 화면으로 돌아가 원본 가져오기·화자 설정·편집·번역·더빙을 진행합니다.
  6. 엔진은 콘솔 창 없이 백그라운드에서 실행되며, 트레이 메뉴에서 상태를 확인하고 종료하는 방식으로 사용합니다.
설치 및 트레이 연결 코드 안내
  1. ZIP 전체를 쓰기 가능한 로컬 폴더에 압축 해제하세요.
  2. 2026-10-22-launch.cmd를 실행하고 설치 안내를 확인한 후 YES를 입력하세요.
  3. 트레이 아이콘에서 ‘웹 연결 코드’를 눌러 8자리 코드를 확인하고 웹 화면의 연결 코드 칸에 입력하세요. 설치 후에는 2026-10-22-engine-start.vbs로 시작하면 실행 창 없이 트레이에서 동작합니다. 웹 화면의 연결 버튼을 사용하세요.

Windows x64용 베타 설치 준비 패키지입니다. 다른 PC 전체 설치는 미검증입니다. 인터넷 연결과 충분한 저장 공간(40GB 이상 여유 권장)이 필요하며 GPU 드라이버는 별도 준비해야 합니다. TTS·음성 인식 모델은 해당 기능을 처음 사용할 때 추가 다운로드합니다.

시작 전에 확인하세요.

웹사이트에 접속하면 바로 설치되나요?

아니요. 다운로드한 패키지를 직접 실행하고 설치 동의를 해야 합니다. 현재 페이지는 매뉴얼·다운로드 안내이며, 웹 편집 화면은 로컬 엔진과 연결해 사용합니다. 실제 음성 처리는 사용자 PC에서 실행하도록 구성합니다.

기존 Python이나 Ollama가 바뀌나요?

기존 Python·패키지·FFmpeg·Ollama·모델을 검사해 호환 항목은 재사용합니다. 기존 환경은 덮어쓰지 않으며 부족한 패키지는 별도 환경에 준비합니다. 기존 서버는 종료하지 않습니다. 엔진 포트는8766, 자체 Ollama는11435이며 실행 중인 기존 Ollama는 그 주소로 연결합니다.

화자를 자동으로 구분하나요?

현재는 수동으로 화자를 등록하고 구간에 배정합니다. 서로 다른 목소리가 필요하면 인물별 참조 음성을 지정하세요. 샘플이 없으면 기본 목소리입니다.

영상과 완벽하게 시간이 맞나요?

발화의 속도와 길이를 보존하므로 긴 대사가 다음 구간을 지연시킬 수 있습니다. 번역·발음·추가 발화·동기화는 최종 검수가 필요합니다.

음성이나 대본이 외부로 전송되나요?

기본 Ollama 번역과 음성 생성은 로컬입니다. 모델 다운로드와 YouTube 가져오기는 인터넷을 사용합니다. 외부 번역 API를 선택하면 대본이 지정한 제공자에게 전송됩니다. 권한이 있는 자료와 목소리만 사용하세요.

Local Voice Studio · Windows 베타 · 모델과 의존성은 각 제공자의 이용 조건을 따릅니다.
