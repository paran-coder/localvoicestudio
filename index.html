처음 사용하시나요?

  1. 아래 Windows 설치 프로그램 다운로드를 누르세요.
  2. 다운로드가 끝나면 브라우저 오른쪽 위 다운로드 목록에서 받은 EXE 파일을 열어주세요.
  3. 설치 창에서 설치 시작을 누르고 변경 내용을 확인하세요.
  4. 설치 창에 로컬 준비 확인 완료가 나오면 이 페이지로 돌아와 스튜디오 시작을 누르세요.
Windows 설치 프로그램 다운로드다운로드만으로 설치되지는 않습니다. 받은 파일을 직접 열어야 설치 창이 나타납니다.

이미 설치하셨나요?

  1. 아래 스튜디오 시작을 누르세요.
  2. ‘Local Voice Studio 열기’ 같은 앱 실행 확인 창이 나타나면 열기를 선택하세요.
  3. 로컬 승인 창에 표시된 사이트 주소를 확인하고 승인하세요.
  4. 상단 버튼이 엔진 연결됨으로 바뀌면 작업을 시작하세요.
아무 창도 나타나지 않거나 연결되지 않으면 연결 문제 해결을 선택하세요.
01 / SOURCE

원본 가져오기

서버 연결을 확인하고 있습니다…

링크의 자막을 먼저 사용합니다. 자막이 없으면 Whisper로 인식합니다. 링크와 파일이 모두 있으면 링크를 사용합니다.

02 / VOICE

목소리 설정

여러 인물로 더빙하기

인물마다 참조 음성을 선택하고 자막의 화자를 지정하세요. 샘플이 없으면 기본 목소리로 생성됩니다. 자동 화자 인식은 하지 않습니다.

인물을 등록하지 않았을 때 사용하는 샘플입니다. 여러 인물 모드에서는 각 인물의 샘플을 사용하며, 없는 인물은 기본 목소리로 생성합니다.

CFG는 생성 지침 강도입니다. 정확한 말하기 속도 조절값은 아닙니다.

03 / SCRIPT

대본과 번역 편집

Enter: 구간 분리 · Shift+Enter: 줄바꿈 · 행 시작 Backspace: 앞 구간과 합치기 · Ctrl+Z: 구간 편집 되돌리기. 분리 시 시간은 글자 비율로 추정하므로 확인하세요.

아래 문장이 실제로 읽힙니다. 번역 결과도 여기에서 검토·수정하세요. 구간은 겹치지 않게 설정하세요.

시작 (초)종료 (초)화자읽을 문장 / 번역문편집

04 / GENERATE

음성 생성

검토한 대본과 화자 설정으로 더빙을 만듭니다.

기본으로 번역 후 더빙합니다. 이미 번역한 대본을 그대로 읽으려면 해제하세요. 영어 생성 시 한국어가 남아 있으면 중단합니다.

설정 도움말

합성된 대사를 원래 속도와 길이 그대로 보존합니다. 배속 조정·자동 축약·대사 무음 대체를 하지 않습니다. 대사가 길면 다음 구간이 늦어질 수 있어 영상 동기화는 별도로 확인해야 합니다. 효과음 표기는 읽지 않습니다. 체크 해제 시 원본 시간의 빈 간격 없이 대사를 이어 붙입니다.
