처음 실행할 때

  1. ZIP을 다운로드하고 쓰기 가능한 로컬 폴더에 모두 압축 해제하세요.
  2. 2026-10-22-launch.cmd를 실행하세요. 설치 안내를 확인하고 YES를 입력하면 전용 Python·필수 패키지·FFmpeg·Ollama·번역 모델을 내려받습니다.
  3. 설치가 끝나고 서버가 켜지면 http://127.0.0.1:8765에 접속하세요. 실행 창은 켜 두세요.
  4. TTS와 음성 인식 모델은 해당 기능을 처음 사용할 때 추가로 다운로드합니다.

Windows x64용 베타 부트스트랩입니다. 깨끗한 다른 PC의 전체 설치는 아직 검증하지 않았습니다. 인터넷 연결과 충분한 저장 공간(40GB 이상 여유 권장)이 필요합니다. CPU에서도 시도할 수 있지만 매우 느릴 수 있으며, GPU 드라이버는 별도로 준비해야 합니다.

시작 전에 확인하세요.

웹사이트에 접속하면 바로 설치되나요?

아니요. 다운로드한 패키지를 직접 실행하고 설치 동의를 해야 합니다. 웹사이트는 소개와 다운로드를 제공하고 실제 처리는 사용자 PC에서 실행합니다.

기존 Python이나 Ollama가 바뀌나요?

배포용 폴더 안에 전용 실행 환경을 준비하며 전역 PATH를 변경하지 않습니다. 번역 서버는 11435, 앱은 8765 포트를 사용합니다. 기존 앱과 동시에 같은 포트를 사용할 수 없습니다.

화자를 자동으로 구분하나요?

현재는 수동으로 화자를 등록하고 구간에 배정합니다. 서로 다른 목소리가 필요하면 인물별 참조 음성을 지정하세요. 샘플이 없으면 기본 목소리입니다.

영상과 완벽하게 시간이 맞나요?

발화의 속도와 길이를 보존하므로 긴 대사가 다음 구간을 지연시킬 수 있습니다. 번역·발음·추가 발화·동기화는 최종 검수가 필요합니다.

음성이나 대본이 외부로 전송되나요?

기본 Ollama 번역과 음성 생성은 로컬입니다. 모델 다운로드와 YouTube 가져오기는 인터넷을 사용합니다. 외부 번역 API를 선택하면 대본이 지정한 제공자에게 전송됩니다. 권한이 있는 자료와 목소리만 사용하세요.

Local Voice Studio · Windows 베타 · 모델과 의존성은 각 제공자의 이용 조건을 따릅니다.
