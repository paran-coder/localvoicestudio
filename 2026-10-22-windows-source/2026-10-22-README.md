# Local Voice Studio Windows beta bootstrap v1.0.0

현재 최종본에서 분리한 배포용 복사본(UI1.3.1 / engine1.1.0). 기존 최종본 수정 없음.
ZIP 전체 압축 해제 후 2026-10-22-launch.cmd 실행. 최초 실행 시 YES 동의 후 준비를 시작한다. 관리자 설치/시스템 PATH 수정 없이 앱 내부 tools/cache/runtime에 전용 환경을 구성한다. 자동 다운로드: Astral uv·Python3.11, PyTorch2.10(CUDA12.8 또는CPU), 현 로컬환경 패키지 snapshot, imageio-ffmpeg0.6, Ollama standalone·gemma4:latest. TTS/STT는 첫 기능 사용 시 다운로드.
NVIDIA 드라이버는 별도 준비. Ollama는127.0.0.1:11435, 앱8765. 기존 프로그램과 포트 충돌 시 기존 앱을 사용자가 종료해야 한다. 최소40GB 여유 권장, 모델에 따라 증가. 설치중인터넷필수, CPU매우느릴수있음.
현재PC에서 추가 설치/모델 다운로드를 실행하지 않았다. 스크립트 문법·패키지 구조 검증만 완료했으며 깨끗한Windows에서 전체설치는 미검증. 재실행 시 설치 표식이 없으면 설치 단계를 재시도한다. 실패 시 창의 오류와cache/temp로그를 확인.
0바이트 참조음성 문제 등 기존 앱 제한은 그대로다. 소스 snapshot의 모든 pins가 다른환경에서도 설치가능한지는 베타테스트 대상. uv/Ollama는 공식latest배포를 사용하므로 설치 시점 버전 차이가 있다. 모델과 패키지는 각 upstream이용조건을 확인.
