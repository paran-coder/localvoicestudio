# Windows 배포 패키지 v1.2.0 — 기존 환경 재사용

1. 2026-10-22-engine-start.vbs 실행. 처음에는 설치 확인 창을 표시합니다.
2. 설치기는 Python·패키지·FFmpeg·Ollama·모델 캐시를 먼저 검사하고 계획을 표시합니다.
3. 계획 확인 후 YES를 입력하면 호환 항목은 재사용하고 없는 항목만 준비합니다.
4. 이후 실행은 창 없이 Windows 기본 트레이에서 관리합니다. 웹 연결 코드를 확인해 웹 매뉴얼에 입력하세요.

- 호환 Python 실행 환경이 있으면 그대로 사용하고 패키지를 덮어쓰지 않습니다.
- Python만 있거나 패키지가 부족하면 별도 venv에서 기존 패키지 경로를 읽고 필요한 버전만 준비합니다. 기존 환경 자체는 수정하지 않습니다.
- FFmpeg가 있으면 재사용합니다. 없으면 앱 내부 tools에 준비합니다.
- 실행 중인 Ollama가 gemma4:latest를 제공하면 연결합니다. 기존 서버는 종료하지 않습니다.
- 꺼진 Ollama의 실행 파일과 모델 저장소를 찾으면 그대로 사용해 별도 프로세스를 시작합니다. 앱이 시작한 프로세스만 종료합니다.
- 기존 TTS/Whisper 캐시는 경로로 재사용합니다. 없는 가중치는 기능을 처음 사용할 때만 다운로드합니다.
- 기본 탐지: 앱 내부 런타임, 같은 프로젝트의 이전 최종본 런타임, PATH 및 Python3.11 설치 경로/레지스트리. 다른 경로는 install.ps1 -PythonPath 절대경로 로 지정할 수 있습니다.
- 기존 Python·캐시를 삭제하거나 이동하면 재사용 경로가 끊깁니다. 이때 설치기를 다시 실행해 검사하세요.

검사만 하기: powershell -NoProfile -ExecutionPolicy Bypass -File 2026-10-22-install.ps1 -CheckOnly
