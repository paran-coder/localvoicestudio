# Windows engine v1.3.0

Unzip the complete package in a writable folder and run `2026-10-22-launch.cmd` once. Review reuse detection and type YES to configure missing dependencies and register `localvoicestudio:` under HKCU. Existing incompatible protocol registrations are preserved and cause an error. No startup task, tray, or always-on service is created.

Then click Studio Start on the web editor. Approve the browser app-open dialog and the local window displaying the exact website origin. No numeric code is needed. Each tab receives an independent short-lived launch approval and authenticated heartbeat.

After the final tab closes/disconnects or stops responding for 180 seconds, the engine exits when queued/running jobs finish. Closing a page does not cancel active jobs. Hidden or suspended browser tabs can stop sending heartbeats; after suspension, click Start again if needed. Keep the editor open until downloads finish. Results remain in this package's results folder; cross-session recovery UI is not provided.

The hidden launcher exits with the engine. Its own Ollama process is stopped; existing external Ollama is left alone. Translation requests set keep_alive=0 to unload the requested model after each request. TTS models are loaded when needed and released when the worker exits. The earlier separate 8765 app is unaffected and can continue using its own resources.

The website cannot detect installation from a failed HTTP request. Failure means stopped, blocked, not installed, or incompatible; installation remains a separate explicit action. Move/reinstall requires reviewing the URI registration. Registry changes are part of running the installer, not visiting the website.

Automated tests cover leases, ticket security and HTTP endpoints. Full new-PC installation, actual Windows URI launch and public HTTPS permission flow require real-host testing.
